# Roadmap

This page describes the direction of an independent project, not a promise of delivery dates.

## Current source areas

- Multi-bot lifecycle, voice placement and playback controls
- Search, source resolution and media metadata
- Web and responsive mobile browser UI
- Shared libraries, history, favorites, playlists and recommendation services
- Diagnostics, data migration and recovery tools

## Planned work

1. Extend automated test coverage around Discord reconnects, media failures and storage migrations.
2. Publish clearer API contracts and improve contributor setup documentation.
3. Separate reusable recommendation, indexing and catalog logic from Discord-specific orchestration.
4. Evaluate independent web playback architecture, respecting media licensing and provider terms.
5. Explore mobile app clients after foundational services have stable interfaces and tests.

The goal is to produce a dependable foundation and measure the quality of search and recommendations rather than claiming parity with established music platforms before comparative testing.
