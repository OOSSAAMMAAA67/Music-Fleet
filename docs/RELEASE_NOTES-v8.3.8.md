# Music Fleet v8.3.8

## Command shortcuts

- `س`, `s`, and `S` now skip the current song.
- `ق`, `q`, and `Q` stop playback and clear the queue.
- English command names and aliases are matched without regard to letter case, with or without the configured prefix.
- Added a shortcut routing regression test covering Arabic and English aliases, uppercase input, prefixed commands, and the full `skip`/`stop` names.
