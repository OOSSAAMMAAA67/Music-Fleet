# Music Fleet v8.3.0

## تغييرات الأوامر

- أضيف -avatarall للمالك الأساسي: أرفق صورة واحدة بصيغة PNG أو JPEG أو GIF أو WEBP، وسيحدّث الأسطول صور كل البوتات الجاهزة بالتتابع مع ملخص للنجاح والتعذر.
- أضيف -owners add @user و-owners remove @user لإدارة أكثر من مالك مفوض. إدارة قائمة المالكين وتغيير صور الأسطول للمالك الأساسي فقط.
- أزيلت أوامر الإشراف العامة، والطرد والحظر، وإرسال الرسائل الإدارية، وعرض معلومات أو صور الأعضاء. أعيد ترتيب help ليعرض أوامر المالك الأساسي أولًا.

## استرداد الصوت والإعدادات

- عند انقطاع بث بعد تشغيل طويل، إذا لم تنتج محاولة الاستئناف من موضع متقدم أي صوت، يجرب النظام المسار نفسه من بداية الأغنية. أوامر seek اليدوية تبقى على الموضع المطلوب.
- لم تتغير إعدادات البافر أو استهلاك RAM. تغير حد كاش القرص القابل لإعادة البناء إلى 20 GB أو 30 يومًا، أيهما يأتي أولًا.
- أزيل التوكن المضمن من config.js ومفتاح جلسات الويب المتولد من ملف التسليم. أضف التوكنات في tokens.txt، ويُنشأ مفتاح جلسات جديد تلقائيًا عند التشغيل.
