# Contributing to Music Fleet

Thanks for your interest in Music Fleet. The most useful contributions are focused, testable improvements that help keep playback reliable and the web experience consistent.

## Before opening a pull request

1. Search existing issues and discuss large architectural changes first.
2. Use a new branch. Keep changes small enough to review and explain the trade-offs.
3. Run syntax checks for any modified JavaScript files (`node --check path/to/file.js`). Where practical, run the dependency and configuration checks.
4. Describe the expected behavior, actual behavior, verification performed and any remaining limitations.
5. Remove credentials, account IDs, private URLs, user databases and downloaded media from logs and examples.

Bug reports should include the operating system, Node.js version, repro steps, expected result and a minimal sanitized log. Please do not post bot tokens, private recordings or personal data.

The roadmap records goals, not commitments or feature guarantees.
